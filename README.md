# 로또 발매기

## 프로젝트 개요
간단한 로또 발매기를 구현하는 프로젝트입니다.
- 로또 번호 범위: 1~45
- 로또 1장 가격: 1,000원
- 당첨 등급: 1등~5등

## 기능 요구 사항

### 입력 기능
- [ ] 로또 구입 금액 입력 받기
- [ ] 구입 금액이 1,000원 단위인지 검증
- [ ] 당첨 번호 6개 입력 받기 (쉼표 구분)
- [ ] 보너스 번호 1개 입력 받기
- [ ] 잘못된 입력 시 "[ERROR]"로 시작하는 메시지 출력
- [ ] 예외 발생 시 해당 부분부터 다시 입력 받기
- [ ] IllegalArgumentException 또는 IllegalStateException 발생

### 로또 생성 기능
- [x] 구입 금액에 해당하는 로또 수량 계산
- [x] 1~45 범위에서 중복 없는 6개 번호 생성
- [ ] 생성된 번호를 오름차순 정렬
- [x] 발행 수량과 번호 출력

### 당첨 검증 기능
- [x] 로또 번호 범위 검증 (1~45)
- [x] 로또 중복 검증 (6개 모두 다른 숫자)
- [x] 당첨 번호 중복 검증
- [x] 보너스 번호가 당첨 번호에 포함되는지 검증

### 당첨 판정 기능
- [x] 3개 일치 판정 (5,000원 - 5등)
- [x] 4개 일치 판정 (50,000원 - 4등)
- [x] 5개 일치 판정 (1,500,000원 - 3등)
- [x] 5개 + 보너스 일치 판정 (30,000,000원 - 2등)
- [x] 6개 일치 판정 (2,000,000,000원 - 1등)

### 당첨 결과 출력 기능
- [ ] 등급별 당첨 개수 출력
- [ ] 총 상금 계산
- [ ] 수익률 계산 (소수점 둘째 자리 반올림)
- [ ] 당첨 통계 형식으로 출력
